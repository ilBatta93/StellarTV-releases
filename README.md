# StellarTV — Download & Aggiornamenti Ufficiali

Benvenuto nel repository ufficiale dei rilasci di **StellarTV**.

Questo repository pubblico ospita esclusivamente i file di installazione **APK** per Android, Google TV e Fire TV.
Il codice sorgente principale dell'applicazione risiede in un repository privato separato per proteggere le chiavi di firma e l'infrastruttura di backend.
